# Fulcrum

> Design intelligence for SAP Activate — KDD generation, gap analysis, and decision learning for SAP S/4HANA **Cloud Public Edition**.  
> Built on Claude Code — no external API key required.

---

## What it does

- Reads real SAP process data from **SAP for Me / Process Navigator** (657 processes)
- Uses **Claude Code** as the AI runtime to generate 15 process-specific KDD questions per scope item
- Exports a ready-to-use **5-sheet Excel workbook** (Cover · Instructions · Scope Overview · KDD Master Log · Summary)
- Runs entirely on your laptop — nothing leaves your machine

## Quick start (30 seconds)

```
1. Clone or download this folder
2. Double-click  start.bat
3. Browser opens at http://127.0.0.1:8321
```

`start.bat` handles everything: checks Node.js, installs packages on first run, starts the server, opens the browser.

---

## First-time setup: Load SAP process data

The app ships with `scope-catalog.json` included — **you can skip this step** and start generating KDDs immediately.

To refresh the catalog with the latest SAP release data:

1. Install the Chrome extension: Chrome → `chrome://extensions` → **Load unpacked** → select the `SAPDeckAgent_v26/` folder
2. Open [SAP for Me → Process Navigator](https://me.sap.com)
3. Click the extension icon → **Load Full Catalog** → **Save to Cartridge**
4. In the app go to **Settings → Reload Catalog**

SAP releases every 6 months (February and August). The app warns you if your catalog is outdated.

---

## Generating a KDD log

1. Open the app → **KDD Generator**
2. Pick the client name and project name
3. Select scope items by Line of Business — or search by ID (e.g. `BD6`, `J59`)
4. Click **Generate KDDs**
5. Watch live progress — each item is generated by Claude in ~30–60 seconds
6. Download the Excel from the result card or **Output Files** page

## Sharing with your project team

### Option A — Teams / SharePoint (easiest)
Zip the entire folder (including `scope-catalog.json`). Share via Teams.  
Recipients double-click `start.bat` — done.

### Option B — Internal Git (recommended for teams)
```bash
git clone https://<accenture-internal-git>/s4pc-explore-accelerator
cd s4pc-explore-accelerator
start.bat          # Windows
```
Each team member runs their own local instance.

### Option C — One shared instance (small project team)
One person starts the server. Everyone else connects to that machine's IP:
```
http://192.168.x.x:8321
```
Works on the same office network / VPN. AI generation runs on the host machine.

## Using via Claude Code directly (no browser needed)

If you have Claude Code open in this folder, you can invoke the skill directly:

```
/s4pc-kdd-generator BD6, J59 — Client: Acme Corp, Project: S4H Rollout
```

Claude reads the agent definition in `.claude/agents/`, pulls the process data, and generates the Excel.

## Cloud PE rules enforced

This tool **never** generates questions referencing:

> ABAP · ECC · R/3 · SE16 · SM30 · SE38 · SE80 · user exit · BAdI · CMOD · SMOD ·  
> on-premise · private cloud · table maintenance · SM31 · SM34 · SAP GUI · SAPGUI

All configuration is via **SAP Fiori apps** or **SAP BTP** only.

## Troubleshooting

| Problem | Fix |
|---|---|
| `node` not found | Install Node.js from nodejs.org, restart terminal |
| AI shows "cache fallback" | Claude Code CLI not in PATH — check `where claude` in terminal |
| Blank catalog | Go to Settings → Reload Catalog |
| Excel not downloading | Check `output/` folder — file is there even if download link fails |
| Port 8321 already in use | Change `PORT=8321` in `server.js` line 10, or kill the existing process |
