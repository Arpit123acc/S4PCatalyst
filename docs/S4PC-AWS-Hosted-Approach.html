RECOMMENDED APPROACH

Hosted delivery on AWS

We host the accelerator. The client gets a tile. They need no AWS, no Anthropic account, and no entitlements from us.

What the client needs

AWS accountnot needed

What we run

  • EC2 instance — the accelerator and governance server
  • IAM instance profile — no stored credential
  • Amazon Bedrock — Claude inference
  • Public Cloud Brain — catalog, vectors, graph, experience

The methodology never leaves our side.

Three problems this solves at once

1 Credential expiry disappears. An IAM instance profile issues temporary credentials that AWS rotates automatically — no login to renew, no token to expire, no manual operational task.
2 The client's cloud becomes irrelevant. Clients on Azure, GCP or no public cloud at all are served identically from one AWS account.
3 IP stays protected. Prompts, brain and engine remain on our infrastructure. Only a URL and the deliverables cross the boundary.
Also removes the "no LLM API keys" conflict — an IAM role is not an API key.

Authentication

OAuth2 client credentials per client, or mTLS if their security team prefers.

Isolation

Per-client partitioning in the brain; only anonymised lessons are shared.

Scaling shape: one host serves many clients. Move to a dedicated instance per client only where a contract requires physical isolation.
Standard SaaS integration pattern — no Cloud Connector, no inbound firewall rule on our side.

Validate before committing — three checks, a few days

1 Does Claude Code run against Bedrock in our setup? If yes, the existing architecture is kept unchanged and there is no engine rewrite — the single largest cost item disappears. Confirm against current Claude Code documentation.
2 Does prompt caching behave the same on Bedrock? The $2.25 figure depends on 1.4–1.6 M cached tokens per run. If caching differs, the cost model changes materially. Test with one real functional design.
3 Is the required Claude model available in the region our data residency demands? Client requirement documents and generated code will be processed there.
