# Steering — Product

**What this is:** S4PC Catalyst — an agentic delivery accelerator for **SAP S/4HANA Cloud, Public
Edition** that lets Claude Code deliver clean-core RICEFW objects, with governance, observability,
and anti-hallucination gates built in.

**Who uses it:** RAP / ABAP-Cloud developers, functional leads, and delivery leads building
extensions on S/4HANA Cloud Public Edition.

**What "done" looks like:** a packaged RICEFW object delivered through the 12-step pipeline with
all three quality gates passed, all three human checkpoints approved, released objects only, an
ABAP-for-Cloud lint PASS, unit tests, and a tenant-verification checklist.

**Non-goals:** classical ABAP and any non-clean-core patterns; anything that is not upgrade-safe on
Public Edition.
